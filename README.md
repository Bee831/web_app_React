# web_app_React

### to run the project.
you will need Node.js v22.23.1 and git.

to clone the repository and enter it.
```shell
git clone https://github.com/Bee831/web_app_React
cd web_app_React
```

then install all the dependencies use whatever, but for npm that comes with Node.js.
```shell
npm install
```
and for actually running it.
```shell
npm run dev
```
if you don't get a error you should see URL for localhost that you can paste in your browser (don't close the terminal or the server will stop running).
